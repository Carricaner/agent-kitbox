# agent-kitbox

Small tools for coding agents. Made for personal use, shared for anyone.

## Tools

- [Markdown viewer for Herdr](herdr/markdown-viewer/README.md): read and edit Markdown in a Herdr pane.
- [Status Hub for Herdr](herdr/status-hub/README.md): a panel for Claude Code, Codex and Docker status.
- [ELI5 output style for Claude Code](claude-code/output-styles/eli5/README.md): makes Claude answer in simple words.

Each tool has its own install and usage steps.
