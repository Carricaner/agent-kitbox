# Changelog

## Unreleased

- In git, Preview marks changes since the last commit like an IDE gutter: green bar for new, blue for changed, red mark where lines were deleted. The toolbar shows `+added −removed`.
- Reload button: after a failed save, drop your edits and load the file again. It asks once first.
- Save with ⌘S.
- Save turns gray when there is nothing to save.
- Unsaved edits and failed saves show in yellow.
- The toolbar shows the file name and wraps in narrow panes.
- Each file remembers the view you last picked.
- Buttons highlight on hover.
- Works as a floating window: a title bar with the file name and a close button, dragged by the title bar.

## 0.1.0 — 2026-11-16

- First release.
- Markdown preview, local editing, and Save.
- Side-by-side and top-and-bottom views.
- Refreshes on its own and never overwrites outside changes.
