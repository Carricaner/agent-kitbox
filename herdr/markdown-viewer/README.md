# Markdown viewer for Herdr

Read and edit Markdown in a Herdr pane.

- Shows a live preview beside or above the source.
- Saves local files when you click Save or press ⌘S.
- In git, shows which lines you changed.
- Remote files are read-only.
- Runs only `git show`, to read the last committed version. Never uses the network.

Install and usage: see the [mod instructions](mods/markdown-viewer/README.md).
